A chess engine in 4 KB of Python: negamax with alpha-beta, iterative deepening to a fixed 48,000-node budget, quiescence search, transposition table, killer-move ordering and piece-square evaluation. It plays the make.fun house gauntlet through the env at `MAKEFUN_ENV_URL`, deterministically — no clock, no randomness, no model calls.

## Run it

```sh
python3 main.py
```
